## 👩🏻‍💻 About Me

**제가 고민한 만큼, 사용자는 덜 고민하도록.**

생각에 머무르지 않고, 직접 만들어 확인합니다.

하나의 서비스가 완성되기까지 기획자, 디자이너, 개발자가 서로 다른 관점에서 같은 문제를 바라본다는 것을 여러 프로젝트를 통해 경험했습니다.

그래서 새로운 기능이나 화면을 고민할 때도 단순히 보이는 결과만 생각하지 않습니다.
사용자는 어떻게 이용할지, 디자인은 어떻게 전달되어야 할지, 실제 구현은 가능한지를 함께 고민합니다.

기획부터 디자인, 퍼블리싱, 개발까지 직접 경험한 만큼 각 역할의 언어를 이해하고, 서로 다른 생각을 연결해 더 나은 결과를 만들어가는 사람이 되고자 합니다.
