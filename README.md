## 👩🏻‍💻 About Me

**제가 고민한 만큼, 사용자는 덜 고민하도록.**

궁금한 것은 직접 해보고, 복잡한 것은 정리해야 직성이 풀립니다.

기획부터 디자인, 퍼블리싱, 개발까지 직접 경험하며
각자의 자리에서 무엇을 고민하는지 배웠습니다.

서로 다른 역할과 생각을 연결하고,
우리의 고민을 사용자의 편리함으로 바꾸는
서비스 기획자로 성장하고자 합니다.
